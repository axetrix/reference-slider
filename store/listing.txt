TITLE
Reference Slider

SUMMARY
Image viewer for supported websites: swipe, zoom and save references to local project collections.

DESCRIPTION
A focused image viewer for Pinterest, with simple tools for collecting references for your next project.

Works only on supported Pinterest websites in Chrome. It does not add a viewer to other websites and does not run inside the Pinterest mobile app. Saved collections can be opened from the extension itself.

Open Slider from a feed, search, board or an already open pin. Browse with arrow keys, mouse swipes or touch gestures. Zoom into details, drag around enlarged images, and use Fit to width for long infographics and screenshots.

Save useful pins into named project collections. Revisit just those references in a separate viewer, search your collections, rename them, and remove references you no longer need. Collections are stored locally in your Chrome profile.

Features:
• Large image viewer with circular controls and Lucide icons.
• Keyboard navigation, mouse dragging and touch pinch zoom.
• Screen-sized images by default; original resolution loads automatically when you zoom in.
• Named reference collections with search and duplicate prevention.
• Image details and source links when available from Pinterest.
• No developer-hosted server, advertising or analytics.

Requires an accessible Pinterest page and an internet connection to load images. It does not bypass Pinterest sign-in. Collections do not sync between devices and image files are not stored offline. Video playback is not supported.

Independent project. Not affiliated with or endorsed by Pinterest.
Store screenshots show the actual interface with an AI-generated, blurred demo image.

SINGLE PURPOSE
Help users view Pinterest images and organize them into local reference collections.

STORAGE PERMISSION JUSTIFICATION
Stores user-created collection names and saved reference metadata locally, so users can revisit their collections after restarting Chrome.

HOST ACCESS JUSTIFICATION
Content scripts run only on the supported Pinterest domains to read visible pin images and metadata and to add the viewer. Access to https://www.pinterest.com/* also lets the extension's collection page request a selected pin's details when the user opens Image details.

REMOTE CODE
No remote executable code. All JavaScript and SVG icons are included in the package. Pinterest page responses are parsed as data and are not executed.

DATA DISCLOSURE NOTES
The extension accesses website content (pin images, URLs, titles, descriptions and source links) and stores selected references locally. No analytics or developer data collection endpoint exists. Explain local handling transparently in the dashboard; do not claim that the extension never accesses data.
