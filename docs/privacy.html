Reference Slider Privacy Policy

Last updated: October 14, 2026. Applies to version 1.2.3.

Purpose and page access

Reference Slider is an independent browser extension for viewing Pinterest images and organizing reference collections. It reads image URLs, pin URLs, titles, descriptions and source links from supported Pinterest pages. When you open image details, it may request that pin’s page from Pinterest. It does not read unrelated websites, your general browsing history, passwords or payment information.

Local storage

Collection names, saved pin identifiers, image and pin URLs, titles, descriptions, source links and timestamps are stored locally in your Chrome profile using chrome.storage.local. The extension does not upload your collections to the developer, synchronize them across devices or include analytics, advertising or tracking code. The developer has no remote access to these local collections.

Network requests and external links

Images and pin details load directly from Pinterest and its image servers. These services receive ordinary network information, such as your IP address. Requests to Pinterest may use your existing signed-in browser session; the extension does not read or store your session cookies. Pinterest’s own privacy practices apply to these requests. External source pages open only when you click their links and are governed by those websites’ policies.

Retention and deletion

Saved references remain in your browser profile until you remove them, delete their collection, clear the extension’s data or uninstall the extension. Image files are not stored offline. Removing a local reference does not alter your Pinterest account or boards.

Limited Use

Reference Slider uses accessed data only to provide its image viewer and local reference collections. It does not sell user data, use it for advertising, transfer it to data brokers or use it for unrelated profiling. Its use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact and changes

For questions, use the developer contact information supplied on the Chrome Web Store listing. Updates affecting data practices will be reflected in this policy.

Reference Slider is not affiliated with or endorsed by Pinterest.
